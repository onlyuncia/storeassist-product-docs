# Обозначения требований и соответствие ID

Текст документов — по-русски; идентификаторы требований — латиницей. FR оформляются как «ID / Требование / Проверяемый результат / Связи», NFR дополнены условиями проверки. Критерии AC содержат условие и действие, ожидаемый результат и ссылки на требования. Проверяемый результат не означает, что испытание уже проведено.

`BR` — бизнес-требование, `RULE` — бизнес-правило, `BG` — бизнес-цель. Специальные обозначения контрактов, процессов и моделей сохраняют свой отдельный смысл.
